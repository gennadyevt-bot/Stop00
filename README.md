# STOP VPN v4.0.0

AmneziaWG VPN для Android (ранее WireGuard).

## Что изменилось

- Движок WireGuard заменён на **AmneziaWG** (`com.zaneschepke:amneziawg-android:2.3.7`)
- Добавлена поддержка параметров обфускации: **Jc, Jmin, Jmax, S1, S2, H1–H4**
- Диалоги добавления/редактирования сервера теперь содержат поля AWG
- Версия поднята до **4.0.0**

## Серверная часть

На сервере нужно:
1. Установить `amneziawg-tools` (awg-quick) вместо wg-quick
2. Добавить в конфиг те же параметры Jc/Jmin/Jmax/S1/S2/H1-H4
3. Ключи оставить теми же — меняется только движок + обфускация
